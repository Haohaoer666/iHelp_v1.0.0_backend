# \# 商品FAQ

# \## 问：iHao智能手表日常如何清洁保养？

# 答：使用无绒软布擦拭表身；如果沾染汗液、乳液、防晒霜，可以用少量清水沾湿布巾轻擦，擦完务必完全擦干。\*\*禁止使用肥皂、消毒液、酒精喷雾、超声波清洗设备，不要用吹风机热风烘烤手表\*\*。

# > 详细操作说明：

# 1\. 清洁前将智能手表关机，断开充电底座，取下皮革类表带。皮革表带不可以沾水，只能干擦。

# 2\. 表背的传感器、心率检测镜片需要重点擦拭，表面残留汗液、护肤品会导致心率、血氧检测读数不准。

# 3\. 扬声器、麦克风网孔如果堆积灰尘，可以用软毛刷轻轻扫掉，不要用尖锐硬物戳捅出声孔。

# 4\. 手表支持日常防水，但是不要泡温泉、桑拿，高温水蒸气会破坏密封防水结构。

# > 注意：游泳、出汗运动结束后，建议及时冲洗并擦干手表，避免盐分长期腐蚀外壳密封圈。海水佩戴之后务必用清水冲洗外壳，海水中盐分容易腐蚀金属表壳与密封圈。皮革表带禁止下水，遇水会出现发硬、开裂、褪色，皮革表带进水损坏不在保修范围。

# \## 问：iHao智能手表耗电快怎么办？

# 答：首先查看耗电排行，高刷新率、始终显示、GPS持续后台采集、蓝牙常连都会增加耗电。可以适当降低屏幕亮度，关闭不需要的后台表盘与传感器；重启手表观察续航是否恢复。如果电池健康度已经低于80%，可以申请电池更换服务。

# > 常见耗电场景说明：

# 1\. 开启“始终显示表盘”功能会明显缩短续航，如果不需要可以在显示设置中关闭。

# 2\. 户外运动模式持续开启GPS定位，一小时运动大约消耗15‑20%电量，运动结束记得退出运动模式。

# 3\. 第三方复杂动画表盘、常驻后台的通知推送、心率24小时高频采样都会加剧电量消耗。

# 4\. 低温环境下电池活性下降，冬季户外使用续航会出现临时性缩短，回到常温环境即可恢复。

# > 排查步骤：重启手表 → 关闭非必要功能 → 观察24小时耗电；待机状态下一晚耗电超过15%，建议提交售后检测是否存在硬件漏电故障。

# \## 问：iHao智能手表无法充电是什么原因？

# 答：先检查充电底座与手表背部金属触点，触点有汗液、灰尘会导致接触不良，使用干布把手表背面和充电器金属片擦拭干净；确认充电器使用5V正规适配器，不要使用快充大功率头；摆放手表保证背部完全贴合充电底座。依旧无法充电，提交售后工单检测硬件故障。

# > 补充排查：

# 1\. 不要使用第三方MagSafe大功率快充头给手表充电，手表只支持5V低功率输入，大功率快充头会触发保护停止充电。

# 2\. 充电底座线缆弯折破损、金属触点氧化，也会造成间歇性充不进电，可以更换原装充电底座交叉测试。

# 3\. 手表温度过高/过低会触发电池保护机制，0℃以下或者40℃以上环境手表拒绝充电，放到室温环境等待15‑30分钟再尝试。

# 4\. 如果手表长时间耗尽电量自动关机，需要连续充电至少30分钟才会点亮屏幕，不要充几分钟就拔掉。

# \## 问：iHao智能手表蓝牙频繁断开如何解决？

# 答：确认手表与手机距离保持在10米以内，中间不要有大量墙体、金属遮挡。关闭手机后台省电限制，不要把iHao配套App设置为电池优化、后台冻结。在手表端执行“重置蓝牙连接”，手机端忽略设备后重新配对。

# > 额外提示：手机同时连接多个蓝牙设备（耳机、键盘），会造成蓝牙信道拥挤，出现手表断连；可以暂时关闭其他蓝牙外设做对比测试。系统版本过旧也会带来兼容性断连问题，请将手机系统、手表固件全部更新到最新正式版本。

# \## 问：iHao智能手表心率、血氧测量不准怎么办？

# 答：佩戴手表不要过松，手表底部传感器需要紧贴手腕皮肤，距离腕骨上方一指位置。运动出汗后擦干手腕汗液，汗液会干扰光学传感器读数。纹身、深色皮肤、体毛浓密，都有可能造成血氧心率读数偏差。

# > 注意：手表的心率、血氧仅做日常健康参考，不能替代医疗检测设备；如果持续读数异常，建议调整佩戴方式，依旧无效可以申请售后检测传感器硬件。

# \## 问：iHao智能手表屏幕出现划痕可以保修吗？

# 答：屏幕表面划痕属于外力物理损伤，摔落、摩擦硬物造成划痕不属于出厂质量问题，不在免费保修范围。购买iHao Care+意外保障服务之后，可以享受一次意外屏幕损坏付费优惠更换。日常建议贴专用手表钢化保护膜，减少外壳磨损。

# \## 问：iHao手机屏幕脏了该怎么清理？

# 答：使用干燥无绒软布擦拭屏幕；污渍较重时可以微微打湿软布再擦拭，\*\*不要直接向屏幕喷洒液体\*\*。不要使用酒精、消毒水、研磨类清洁纸巾，会腐蚀屏幕疏油涂层，造成屏幕容易留指纹、出现划痕。

# > 注意：手机接口、听筒不要插入棉签、针等尖锐物品清理，容易捅坏内部弹片。灰尘堆积建议使用软毛刷轻轻扫掉。不要把手机放到超声波清洗设备清洗，会破坏密封胶，造成设备进水隐患。

# \## 问：iHao手机卡顿、应用闪退怎么处理？

# 答：优先重启手机；确认系统版本更新到最新正式版本；闪退的App可以尝试卸载重装；检查存储空间，剩余存储空间低于10GB容易出现卡顿闪退。重启更新之后故障依旧，需要检测是否存在硬件故障。

# > 深度排查：

# 1\. 如果只有某一个App闪退，大概率是App本身适配问题，等待App开发者更新版本。

# 2\. 手机存储空间几乎占满，系统没有缓存空间，会出现动画掉帧、切换App卡顿、拍照保存失败。建议至少保留15GB以上空闲存储。

# 3\. 手机长时间高温（暴晒、玩大型游戏）系统会主动降频，表现为卡顿，冷却后恢复。

# 4\. 升级大版本系统之后，前1‑2天系统会在后台做索引重建，这个阶段手机会卡顿发热，属于正常现象。

# \## 问：iHao手机电池健康下降太快怎么办？

# 答：尽量避免长时间满电存放、避免长期高温环境（暴晒、被窝充电）；尽量使用官方原装充电配件。当电池最大容量下降至80%以下，在保修期内可以申请电池更换服务。人为老化损耗不在免费保修范围内。

# > 电池养护小知识：

# 1\. 尽量维持电量20%‑80%区间，不要经常用到0%自动关机，深度放电会加速电池老化。

# 2\. 边玩大型游戏边充电会产生大量热量，高温是锂电池最大损耗来源，尽量避免。

# 3\. 第三方非认证充电器电压电流不稳定，长期使用会加速电池衰减，优先选用官方充电套装。

# \## 问：iHao手机信号差、移动网络网速慢如何排查？

# 答：开启飞行模式等待10秒再关闭，重置蜂窝网络连接；确认所在位置运营商信号覆盖；取出SIM卡擦拭金属芯片后重新安装；设置‑网络中重置网络设置。

# > 重置网络设置不会删除照片文件，只会清除WiFi密码、蓝牙配对记录。升级系统版本也会修复部分基带信号兼容性bug。如果同一地点别的手机信号正常，本机持续信号弱，可以提交售后检测天线硬件。

# \## 问：iHao手机Wi‑Fi连接上但是无法上网？

# 答：先确认其他设备连接同一个Wi‑Fi是否正常；忽略此Wi‑Fi重新输入密码连接；重启家里路由器；手机端执行重置网络设置。靠近路由器，远离微波炉、蓝牙设备，减少2.4G信道干扰。

# \## 问：iHao手机相机拍照模糊是什么原因？

# 答：擦拭镜头玻璃，指纹油污是拍照模糊最常见原因；撕掉镜头位置保护膜；拍照时等待对焦框锁定之后再按下快门；近距离拍摄不要小于设备最近对焦距离。如果镜头内部进灰、镜片碎裂属于硬件故障，需要售后检测。

# \## 问：iHao平板触屏失灵、局部断触怎么处理？

# 答：撕掉第三方厚钢化膜测试；擦干屏幕表面汗液、水渍；重启平板；如果屏幕受过摔落挤压，大概率为屏幕硬件损坏，提交售后检测。不要使用导电液体喷洒屏幕。

# > 补充场景：低温环境下平板屏幕灵敏度会轻微下降；充电时使用非原装充电器，会出现屏幕乱跳、误触现象，更换原装充电器即可恢复。

# 

# \## 问：iHao平板无法开机怎么排查？

# 答：连接原装充电器持续充电至少30分钟，低温环境平板会触发电池保护，充一段时间再尝试开机；长按电源键强制重启。完全无反应则可能是电池或者主板故障，需要送修。

# > 注意：平板电量完全耗尽关机后，不要断断续续插拔充电器，需要持续供电激活电池。设备进水后不开机，禁止反复长按开机尝试，会造成主板短路烧毁。

# 

# \## 问：iHao平板外放扬声器没有声音？

# 答：检查设备是否开启静音模式、音量是否调至最低；播放音乐确认媒体音量；查看扬声器网孔是否被保护膜、外壳遮挡；清理网孔灰尘；连接蓝牙耳机测试，如果蓝牙耳机有声音，代表本机外放扬声器故障，申请售后检测。

# 

# \## 问：iHao平板充电充得慢是什么原因？

# 答：平板支持快充，但是温度过高会自动限制充电功率。玩游戏、看视频同时充电速度会明显变慢。尽量息屏充电，使用官方适配器与数据线；数据线老化破损也会导致充电功率下降。

# \## 问：iHao蓝牙耳机没有声音、单边无声怎么办？

# 答：放回充电仓合上盖子等待10秒，重新取出配对；清理耳机出声网孔，耳罩网被耳垢堵塞会音量变小；手机端忽略此蓝牙设备，执行重置耳机后重新连接。

# > 耳机清洁提示：耳机出声孔使用软毛刷清理，\*\*严禁用水直接冲洗耳机本体\*\*；充电仓金属触点定期干布擦拭，保证充电接触正常。

# \## 问：iHao蓝牙耳机续航变短是什么原因？

# 答：蓝牙耳机电池属于消耗配件，循环充放电次数变多之后续航会自然衰减。如果单耳或者充电仓续航明显大幅跳水，保修期内可以申请检测更换配件。

# > 使用提示：长期不使用耳机，建议保持50%左右电量存放，不要满电或者电量耗尽长期搁置，会加速电池老化。充电仓盖子务必关好，耳机未放回仓内会持续耗电。

# 

# \## 问：iHao蓝牙耳机蓝牙经常断连如何解决？

# 答：远离路由器、微波炉等2.4G干扰源；手机与耳机之间不要有金属遮挡；删除蓝牙配对记录，重置耳机重新配对；更新手机系统与耳机固件。

# > 多设备切换提示：耳机同时记忆多台手机设备，多台设备同时开机会出现耳机来回跳设备，不用的设备上面取消配对即可。

# 

# \## 问：iHao蓝牙耳机降噪效果变差怎么办？

# 答：耳塞套没有贴合耳道会直接降低降噪效果，尝试更换尺寸硅胶耳塞；出声孔、麦克风孔耳垢堵塞，会破坏降噪算法采集；使用软毛刷清理孔洞。佩戴的时候耳机不要松动晃动。更新耳机固件，厂商经常会优化降噪算法。

# 

# \## 问：iHao蓝牙耳机充电仓充不进电？

# 答：擦拭充电仓底部充电接口金属触点，同时擦拭耳机柄金属触点；更换数据线与充电头；充电仓指示灯完全不亮，长时间充电无反应，大概率充电仓硬件故障，提交售后。

# \## 问：iHao设备进水了该如何处理？

# 答：立刻关机，断开所有充电线缆。使用干布擦干表面，放置通风处充分晾干。\*\*禁止开机、禁止充电、禁止吹风机热风烘烤\*\*。进水腐蚀属于人为损坏，不在免费保修范围，建议尽快提交付费检测。

# > 重要提醒：防水功能不是永久有效，摔落磕碰会破坏机身密封胶，即使之前防水，摔过之后防水能力下降，进水不在保修。不要拿设备做水下长时间浸泡测试。

# 

# \## 问：iHao手机/平板忘记锁屏密码怎么办？

# 答：连续输错密码会触发设备锁定；如果开启账号绑定，可以登录iHao账号网页端执行远程抹除设备，抹除后设备恢复出厂，但是本机全部照片资料会全部清空。没有开启账号绑定，则只能通过官方售后做整机清除数据，设备内部所有数据无法保留。\*\*日常请做好数据云备份。\*\*

# 

# \## 问：iHao设备数据如何备份？

# 答：可以使用iHao云空间进行云端备份，也可以连接电脑使用桌面客户端完成本地全量备份。建议重要照片、聊天记录定期备份，维修、送修之前建议自行备份数据；售后维修过程中不保证保留用户设备内部个人数据。

# 

# \## 问：设备送修邮寄注意事项？

# 答：寄回维修请使用原包装盒加厚包装，防止运输途中二次摔损；不要邮寄耳机、保护壳、充电器等非故障配件；在包裹内纸条写明订单号、故障现象、联系电话。不要发到付快递，到付包裹仓库会直接拒收。

# 

# \## 问：换新机器之后保修时间怎么算？

# 答：符合政策换货拿到全新机器，新机器重新计算12个月整机保修。维修更换配件，配件保修跟随原设备剩余保修时间，不会重新计时。

# 

# \## 问：第三方配件会对iHao设备造成什么影响？

# 答：未经过iHao认证的充电器、数据线，可能出现电压不稳，造成电池加速老化，极端情况会烧毁主板；使用第三方非官方屏幕，会丢失原机部分传感器功能，同时整机直接失去免费保修资格。
