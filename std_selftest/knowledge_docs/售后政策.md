# \# 售后政策

# \## 退货政策

# 支持签收后7天内无理由退货。签收时间以物流系统显示的签收日期为准，自签收当日开始计算7天有效期，超时将不再受理无理由退货申请。

# 商品需保持完好，不影响二次销售。商品本体、外包装盒、原厂配件、说明书、赠品需要一并完整退回；商品不能出现人为磕碰、划痕、进水、污渍、拆解改装、部件缺失等情况。如果商品已经出现明显使用损耗、损坏、缺少配件，商家有权拒绝无理由退货申请。

# 具体运费承担以平台售后规则为准。

# 1\. 商品本身存在质量问题：退货运费由商家承担，用户需要保留快递面单以及商品故障照片凭证。

# 2\. 用户个人原因发起7天无理由退货：退回运费由用户自行承担；如果订单原本包含运费险，则按照运费险理赔规则进行补偿。

# 3\. 特殊品类不支持七天无理由：消耗类耗材、已经拆封的贴身用品、定制类商品，不适用7天无理由退货政策。

# 

# > 退货操作流程：用户在订单详情页提交退货申请，等待商家审核；审核通过后按照系统给出的退货地址寄回；商家签收退回商品并完成验货，验货无误后处理退款。退款原路返回原支付渠道，到账时间取决于支付平台处理周期，一般1‑7个工作日。

# 

# > 拒绝退货常见场景：超过7天签收时效；商品人为损坏、配件丢失；耗材已拆封使用；定制定制化商品。

# 

# \## 换货政策

# 签收后15天内可申请换货。签收时间以物流签收记录为准，15天时效从签收当天起算。

# 需提供商品问题照片，清晰展示故障位置、商品外观、商品型号信息；提交换货售后工单，上传对应图片凭证。客服审核通过后，用户按照售后地址把问题商品寄回，商家收到并且检验确认故障属实之后，重新发出全新替换商品。

# 

# 1\. 非人为质量故障：来回运费由商家承担。

# 2\. 用户人为损坏、磕碰进水导致故障，不支持免费换货，用户可选择付费维修。

# 3\. 换货库存不足场景：如果同款商品暂时缺货，可协商转为全额退款处理。

# 

# > 换货注意事项：寄回时请附带原包装以及配件；不要直接到付邮寄，到付包裹仓库会直接拒收。

# 

# \## 运费说明

# 普通商品满 99 元包邮。订单实付金额（扣除优惠券、红包之后的实际支付金额）满99元，普通地区享受包邮服务。

# 不满 99 元时，普通地区运费为 8 元。

# 偏远地区运费根据系统计算，下单前以结算页为准。

# > 偏远地区包含新疆、西藏、内蒙古部分区域、青海、宁夏等，具体以下单结算页面展示运费为准。

# > 包邮活动仅针对普通快递，不包含顺丰、特快、上门加急等增值快递服务，如果用户主动选择特快快递，需要补对应差价。

# > 部分大件商品会有额外大件物流费，该费用不受满99包邮规则覆盖，结算页会单独展示大件运费。

# 

# \## 售后通用提示

# 1\. 所有售后申请，请优先在平台订单页面提交工单，不要只通过聊天发送图片，聊天记录不作为正式售后申请凭证。

# 2\. 售后处理时效：商家一般会在1‑3个工作日完成售后审核；退回包裹签收后，验货处理时效一般1‑5个工作日。

# 3\. 如果对售后审核结果存在异议，可以申请平台介入，上传照片、聊天记录等举证材料。
