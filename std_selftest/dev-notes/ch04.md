## RAGAS 生成质量评估

- 保留原有四策略检索评估，不把自定义 Recall@K / MRR 替换掉。
- 新增 `RAG_test/scripts/eval_ragas_ch04.py`，作为独立的生成质量评估层。
- 使用 RAGAS `0.4.3`，指标包括：
  - Faithfulness
  - Answer Relevancy
  - Context Precision
  - Context Recall
- 由于 RAGAS 调用次数高、耗时较长，默认只评估 `hybrid_rerank`，并支持 `--strategies` 扩展。
- 初始全量运行遇到 Faithfulness NLI 输出超过 `max_tokens`。
- 调整：
  - `max_tokens=16384`
  - `--ragas-top-k 5`
  - 单指标失败不终止整体评估，写入 `errors`
  - 增加逐条进度输出
