## 返工记录

- MySQL `milvus_id` 最初使用 INT，Milvus 自增 ID 超出 32 位导致 out of range，改为 BIGINT。
- Milvus COSINE 返回更高的分数代表更相似，初始过滤条件写反，导致召回错误。
- `rebuild=false` 最初仍重复插入相同 `chunk_id`，增量建库会触发唯一键冲突；已改为先读取已有 `chunk_id`，已存在则跳过并只补齐 pending / failed 块。
- 知识库路由中的同步 DB、HTTP、Milvus 操作已从 `async def` 改为普通 `def`，由 FastAPI 线程池执行。
- 新增 `document_loader.py`，支持 Markdown、DOCX、文字型 PDF；PDF 页面文本过少时自动走 RapidOCR。
- Milvus `category` 字段按字节限制 255，中文路径容易超限；写入前统一截断 `category`、`chunk_id` 和 `text`。
- 文档读取从旧 `fitz` 导入迁移到 `pymupdf`，避免弃用警告。
- Milvus 向量库从默认 database 切换到专用 database `Haohelper`，collection 保持 `knowledge`。
- 已完成旧向量迁移：`default.knowledge` -> `Haohelper.knowledge`，按 MySQL 当前 `chunk_id` 去重后迁移 202 条。
- 前端输入“华为智慧屏怎么连接设备”已完成端到端验证：选中 `query_faq`，Milvus 召回智慧屏接口和互联说明，SSE 正常返回并显示工具轨迹徽章。
- 新增 `.doc` 支持：Windows 环境通过 pywin32 调用 Microsoft Word COM，将 `.doc` 临时转换为 `.docx` 后复用现有 DOCX 读取流程。
